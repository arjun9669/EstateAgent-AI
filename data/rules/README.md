# Rule documents

`search_rules` indexes every `.md` and `.txt` file in this folder except this
README. The legislation files are generated by `scripts/fetch_rules.py` from the
Dubai Legislation Portal; do not edit them by hand. Sources and limitations:
[docs/DATA_SOURCES.md](../../docs/DATA_SOURCES.md).

Format: the first `# ` line is the document title. Each `## ` heading starts a
section (one article of a law), which is the unit returned and cited, e.g.
`law-26-2007#art14`. Text before the first section is not indexed.
