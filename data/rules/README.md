# Rule documents

`search_rules` indexes every `.md` and `.txt` file in this folder except this
README. It is empty in milestone 1: official documents are added in milestone 2
after their terms are checked. See [docs/DATA_SOURCES.md](../../docs/DATA_SOURCES.md).

Format: one document per file. The first line beginning with `# ` is used as the
document title in citations. Separate passages with blank lines.
