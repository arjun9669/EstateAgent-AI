# EstateAgent AI

An agentic RAG assistant for the Dubai property market: a LangGraph agent that
plans tool calls over listings, market data, mortgage rules and official Dubai
tenancy law, and checks every figure in its answer against the tool results.

Listings and sales data are synthetic. Information only, not legal or financial advice.

Source code, tests and documentation: https://github.com/arjun9669/EstateAgent-AI
